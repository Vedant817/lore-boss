## 4. Non-blocking flags

**N1 · `#freshness` can remain empty on a first-load failure (pre-existing, not introduced).**
Path `app.js:122-127` (+ `:693`). Trigger: `lastSyncMs === 0` (first `/api/status` fails or returns the wrong shape) — `renderFreshness` returns early and `$('freshness').textContent` is never set, so the caption is blank rather than saying anything. (b) `presentation.spec.ts:83` — `expect(page.locator('.ov-portrait')).toHaveCount(0)` passes for any page, so `:84-85` (asserting the served stylesheet has no `.ov-portrait`) is the assertion that actually guards the removal; both are present, so no action is needed.
